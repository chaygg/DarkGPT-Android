# DarkGPT Android

مشروع Android أولي لتطبيق DarkGPT، بالحزمة `com.darkgpt.chat` وواجهة داكنة ولمسات حمراء.

## البناء
1. ارفع الملفات إلى مستودع GitHub الخاص بك.
2. افتح تبويب Actions.
3. شغّل سير العمل `Build Android APK` أو انتظر تشغيله بعد رفع الملفات.
4. نزّل `DarkGPT-debug-APK` من Artifacts بعد نجاح البناء.

**مهم:** هذه نسخة أولية بواجهة دردشة وردود تجريبية محلية. لا يوجد خادم AI أو مفتاح API مضمّن. لا تضع مفتاح API سريًا داخل التطبيق؛ احتفظ به على الخادم.
